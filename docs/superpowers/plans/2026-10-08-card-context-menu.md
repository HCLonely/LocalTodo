# Card Context Menu Implementation Plan

**Goal:** 主界面禁用右键菜单，小卡片只显示任务管理菜单，不显示浏览器/调试菜单。
**Architecture:** 共享输入策略在两窗口取消浏览器contextmenu默认行为及调试快捷键；卡片使用React菜单调用现有Rust API。窗口配置显式禁用devtools。
**Spec:** 用户本轮右键要求。

- [x] 添加输入策略和卡片菜单：任务右键完成/编辑/移入回收站，空白右键添加/置顶/刷新/主界面/隐藏。
- [x] 菜单支持边缘避让、Esc/外部点击关闭、键盘导航；任务操作失败保留数据并提示。
- [x] 验证默认菜单被阻止、任务菜单调用正确ID、空白菜单置顶及关闭行为、无调试条目。
- [x] 双窗口原生烟雾验证，禁用devtools配置，构建便携程序/ZIP，更新校验并交付。
